# DEEPFAKE DETECTION USING A HYBRID MODEL: VGG16 AND BEIT VISION TRANSFORMER

This is the final project for the course **"Computer Vision"** in the MSc in Artificial Intelligence and Robotics at *Sapienza University of Rome*, academic year 2023/2024.

# Datasets

+ [FFHQ](https://github.com/NVlabs/ffhq-dataset)
+ [Deepfake Challenge Dataset](https://iplab.dmi.unict.it/deepfakechallenge/)

# How to run?

This code was developed using Google Colab and Google Drive to get the Datasets.
In order to train and evaluate the mode you should upload on Google Drive the datasets
you can find in the upper section.
